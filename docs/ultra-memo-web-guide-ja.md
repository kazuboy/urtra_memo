# Ultra Memo Web 使い方ガイド（最新版）

このドキュメントは、現在の Web 版 Ultra Memo の操作方法をまとめたものです。

## 1. できること

- すぐにメモを書けるシンプルUI
- 自動保存（保存ボタン不要）
- 全文検索（タイトル・本文・`#tag`）
- Markdown入力 + プレビュー切替（`M`）
- 最近 / ゴミ箱 / 完全削除
- フォルダ作成・切替・削除（削除時は Main へ移動）
- クリップ履歴（Web版はアプリ内貼り付けで履歴追加）
- インポート / エクスポート

## 2. 基本操作

### 新規メモ

- 上部ツールバーの `+ 新規` で作成

### 編集

- 左のメモカードをクリックして選択
- 右ペインで本文を編集
- 入力停止後に自動保存

### 検索

- 左上の検索欄にキーワード入力
- `#tag` でも絞り込み可能

### 並び替え

- `並び: 更新日 / 作成日` で切替

## 3. 表示モード

- `M`: Markdownプレビュー表示の ON/OFF
- `集中`: 左ペインを隠して1メモ集中表示

## 4. フォルダ

### フォルダ一覧

- 左ペインの `フォルダ一覧` から切替

### フォルダ作成

- フォルダ一覧ウィンドウで名前入力して `追加`

### フォルダ削除

- 左ペインの `削除`（フォルダ削除）
- 確認ダイアログ後、該当フォルダ内メモは `Main` へ移動

## 5. メモ設定（右クリック）

- 左のメモカードを右クリックで「メモ設定」
- タイトル変更
- タグ変更
- 削除 / 復元 / 完全削除

## 6. クリップ履歴

- 左リスト上部の `クリップ履歴` を選択
- Web版はアプリ内での貼り付け（Ctrl+V / 右クリック貼り付け）時に履歴を追加
- `クリア` で履歴削除

## 7. インポート / エクスポート

メニュー (`メニュー` ボタン) の `Data I/O` から実行します。

### エクスポート

- `Export JSON (All notes)`: 全メモを JSON で出力
- `Export Markdown (Selected note)`: 選択中メモを `.md` で出力

### インポート

- `Import file...` で1ファイル選択
- 対応拡張子: `json / md / markdown / txt / text / log / rst / adoc / org`
- 現在仕様: **1ファイル = 1メモ** として新規取り込み

## 8. 保存先と注意

- 保存先はブラウザの `localStorage + IndexedDB`
- 同じブラウザ・同じプロファイルで保持
- ブラウザデータ削除でメモが消えるため、重要データは定期的に JSON エクスポート推奨

## 9. トラブル時の確認

### インポートしても見えない

- 左上の表示が `最近` や `ゴミ箱` になっていないか確認
- `すべて` に戻して確認
- 必要ならハードリロード（Ctrl+Shift+R）

### 表示がおかしい / スクロールできない

- 最新版へ更新後にハードリロード
- それでも再現する場合は、再現手順とファイル名を添えて報告
