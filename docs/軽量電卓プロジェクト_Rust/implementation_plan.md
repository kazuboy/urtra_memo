# 要件定義：極限軽量電卓（Rust版）

## 1. プロジェクト概要
「軽量さ」「単独動作」を追求しつつ、必要十分な機能を備えたWindows用GUI電卓アプリ。

## 2. 機能要件
### 2.1 計算機能
- 四則演算（+, -, *, /）
- パーセント計算（%）
    - `WM_DESTROY` 時にクリーンアップする（任意）。
- 平方根計算（√）
- クリア（C）およびバックスペース（1文字消去）

### 5. デザイン・DPI・GDIリファクタ（フェーズ3）
- **Per-Monitor V2 DPI対応**:
  - アプリケーションマニフェスト、または `SetProcessDpiAwarenessContext` によってDPI対応を宣言する。
  - `WM_DPICHANGED` を受け取り、提供されたスケール率に基づいてウィンドウサイズやコントロールのフォント、マージン等を再スケーリングする。
- **GDIによる視覚表現（軽量化維持）**:
  - GDIネイティブの `GradientFill`（`Msimg32.lib` 相当）を使用するか、擬似的なグラデーション背景を描画して表示領域を美しくする。
  - 静的な「薄い影」は、ボタン領域の後ろにブラー風の色合いを載せた少し大きめの `RoundRect` を描画することで高速・軽量に再現する（アニメーションなし）。
- **完全なリソースキャッシュ（メモリ・速度最適化）**:
  - タイポグラフィと配色を洗練させた専用の `HBRUSH`, `HPEN`, `HFONT` を起動時にすべてバッファリングし、描画時（`WM_DRAWITEM`等）には都度作成せずキャッシュを流用する。
  - プログラム終了時に全てのハンドルを明示的に `DeleteObject` し、GDIリークを完全に防ぐ。
- **レイアウトの統一化**:
  - `0` ボタンの配置を「2列分の横長ボタン」としてグリッド計算に組み込む。
  - 上部の「Size」「Pin」ボタンも `BS_OWNERDRAW` 化し、メインUIと見た目・角丸のテイストを統一する。
- **計算精度**: `rust_decimal`等を用いて、浮動小数点数の計算誤差を排除する。
- **エラーハンドリング**: ゼロ除算や「√ -1」などの無効な操作に対してアプリをパニックさせず、表示部に "Error" 等と明示する。

### 2.2 利便性・運用機能
- **クリップボード連携**: 結果表示エリアまたは `Ctrl+C` で、計算結果をクリップボードにコピー。
- **常に手前に表示（Always on Top）**: 設定により、ウィンドウを他の最前面に保持可能。

## 3. 非機能要件
### 3.1 性能
- **メモリ（RAM）消費**: 実行中に5MB〜15MB以内を目指す。
- **ファイルサイズ**: 単体実行ファイル（.exe）で2MB〜5MB以内を目指す。
- **レスポンス**: 入力に対して即座に反応する（描画遅延ゼロ）。

### 3.2 UI/UX
- **レスポンシブレイアウト**: ウィンドウのリサイズに合わせて、ボタンの配置やサイズが適切に調整される。
- **ダークモード**: システム設定またはアプリ内設定により、ダークテーマを適用可能。
- **スタンドアロン**: 外部DLLやランタイムのインストールを不要とし、exe単体で動作する。

## 4. 技術スタック
- **言語**: Rust
- **GUIライブラリ**: `windows-rs` (Microsoft公式クレート) のみを使用。
    - 理由：極限の軽量化、バイナリサイズの最小化を実現し、追加DLL等なしで動作させるため。最新のWin32 API（ダークモードの拡張等）への直接アクセスも容易。
    - 注意：生のWin32 APIを直接扱うため、ウィンドウクラスの登録やメッセージループ等の低レイヤー実装を自前で行う。

## 6. アプリアイコンの埋め込み計画
### 6.1 依存関係の追加
- `Cargo.toml` の `[build-dependencies]` に `embed-resource` を追加。

### 6.2 ビルドスクリプトの作成
- `build.rs` を作成し、`app.rc` をコンパイルするように設定。
- `app.rc` には既に `id ICON "calculator.ico"` が記述されていることを確認済み。

### 6.3 プログラム修正 (`src/main.rs`)
- `WNDCLASSW` の登録時に `hIcon` および `hIconSm` を設定。
- `LoadIconW` を使用して、リソース ID からアイコンをロード（ID "id" または 1）。

### 6.4 検証フェーズ
- `cargo build --release` を実行し、ビルドが通ることを確認。
- 実行ファイル（`calculator.exe`）のプロパティやタスクバーでアイコンが表示されることを確認。
