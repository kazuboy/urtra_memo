# 超軽量メモアプリ Product Spec (MVP)

## 1. 目的

「一瞬で書けて、一瞬で見つかる」ローカル完結型メモアプリを Rust で実装する。  
初期版では、日常利用での体感速度を最優先し、機能の広さよりも起動・編集・検索の速さを重視する。

## 2. スコープ

### 2.1 MVP In Scope

- 新規メモ作成
- メモ編集
- 自動保存
- Markdown プレーン入力
- メモ一覧表示
- 全文検索
- 最終状態復元（最後に開いていたメモ）

### 2.2 MVP Out of Scope

- クラウド同期
- 共同編集
- 高機能 WYSIWYG 編集
- 画像埋め込み管理
- プラグイン機構
- Web 版

## 3. 対象環境

- OS: Windows（初期版）
- 言語: Rust

## 4. データ方針（採用）

MVP では以下を採用する。

- メモ本体: Markdown ファイル（`.md`）
- 検索: SQLite FTS5 インデックス

理由:

- ユーザーがメモ本文を直接バックアップできる
- 将来の移行が容易
- 検索性能を確保しやすい

## 5. データモデル（論理）

## 5.1 Note

- `id`: 文字列 UUID
- `title`: 文字列（未入力可）
- `body`: 文字列（Markdown）
- `created_at`: UTC datetime
- `updated_at`: UTC datetime
- `deleted`: bool

補足:

- `title` 未入力時は本文先頭行を仮タイトルとして表示する。

## 5.2 AppState

- `last_open_note_id`: Option<String>
- `window_width`: u32
- `window_height`: u32
- `window_x`: i32
- `window_y`: i32
- `last_query`: Option<String>

## 6. 保存レイアウト（案）

- `data/notes/<note_id>.md`: メモ本文
- `data/meta.sqlite3`: メタデータ + FTS インデックス
- `data/state.json`: UI 状態

## 7. 機能仕様（MVP）

## 7.1 新規メモ作成

- 保存先入力なしで即作成できる。
- タイトル未入力でも作成できる。

受け入れ基準:

- 新規作成操作後 1 秒以内に編集開始可能。
- 本文 1 文字以上入力で自動保存対象に入る。

## 7.2 メモ編集 + 自動保存

- 入力停止後、短時間で保存する（デバウンス）。
- 連続入力中は保存頻度を抑える。

受け入れ基準:

- 入力停止から 1000ms 以内に保存キュー投入。
- 連続入力時は過剰 I/O を避け、保存処理が UI 入力を阻害しない。
- 保存失敗時はユーザーに明示通知される。

## 7.3 Markdown プレーン入力

- Markdown をそのまま編集可能。
- リッチ編集は行わない。

受け入れ基準:

- 見出し、箇条書き、番号付き、チェックボックス、コードブロック、インラインコード、リンク、`#タグ` をテキストとして破壊しない。

## 7.4 一覧表示

- 更新日時降順がデフォルト。
- タイトル（または先頭行）、更新日時、抜粋を表示。

受け入れ基準:

- 作成/更新後に一覧が即時更新される。

## 7.5 全文検索

- タイトル + 本文を横断検索。
- 入力中に結果を更新（インクリメンタル）。

受け入れ基準:

- 数千件規模で「体感即時」に候補更新される。
- 検索結果にタイトル（または先頭行）、一致スニペット、更新日時を表示。

## 7.6 起動時復元

- 最後に開いていたメモを復元。

受け入れ基準:

- 通常終了後の次回起動で、直前メモを自動で再表示。

## 8. 非機能目標（MVP）

- 起動: 体感 1 秒未満（理想は数百 ms）
- 保存: 待ち時間を感じさせない
- 検索: 入力ごとに結果更新しても操作感が重くならない
- 安定性: 異常終了時の損失最小化
- 保守性: UI / 保存 / 検索を疎結合

## 9. MVP 評価基準

- 「保存」を意識せずに使えること
- 過去メモを検索で即時発見できること
- メモ帳代替として日常起動したくなる軽さがあること

## 10. 次ステップ（実装前提）

1. Rust プロジェクト骨格を作成（層分離の雛形）
2. 保存層（Markdown）と索引層（SQLite FTS5）の最小実装
3. 一覧・検索・編集の最小 UI 接続
4. 自動保存と復元を統合
5. MVP テスト追加
